# 포스터 자동 생성 서비스

텍스트와 이미지를 입력하면 AI가 자동으로 배치한 포스터를 만들어주는 Next.js 웹 애플리케이션입니다.

## 주요 기능

- **자동 레이아웃 생성**: 텍스트·이미지 분량과 비율을 분석해 최적의 레이아웃 3종을 제안합니다.
- **레퍼런스 이미지 반영**: 레퍼런스 이미지의 색상 팔레트·폰트 분위기·레이아웃 구조를 포스터에 적용합니다.
- **파일 내보내기**: 완성된 포스터를 `.pptx`, `.docx`, `.tex(LaTeX)` 형식으로 다운로드할 수 있습니다.
- **Instagram 내보내기**: 각 이미지에 텍스트 오버레이를 합성해 카루셀 PNG로 내보냅니다.
  - `[이미지N]` 마커로 이미지별 텍스트를 자동 매칭
  - GPT-4o Vision으로 이미지 내용을 분석해 관련 텍스트 자동 추천
  - 레퍼런스 색상·폰트를 오버레이에 반영
  - 해시태그 자동 추천 및 캡션 복사
- **세션 제한**: OpenAI 호출 10회, 레이아웃 조정 5회 제한으로 비용을 관리합니다.

## 기술 스택

| 항목 | 기술 |
|------|------|
| 프레임워크 | Next.js (App Router) |
| 언어 | TypeScript (strict) |
| 스타일 | Tailwind CSS v4 |
| 이미지 합성 | sharp |
| AI | OpenAI GPT-4o, GPT-4o-mini (Vision + 텍스트) |
| 파일 생성 | pptxgenjs, docx, jszip |

## 환경 변수

`.env` 파일에 아래 키를 설정하세요.

```
OPENAI_API_KEY=sk-...
```

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 열면 됩니다.

## 주의 사항

- `.env` 파일은 절대 커밋하지 않습니다 (`.gitignore`에 등록됨).
- 이미지·텍스트는 서버에 저장되지 않으며, 브라우저 메모리에서만 처리됩니다.
